## 证据层与超图建模

核心思想：用“超图”统一多源证据。顶点为 contig，超边为“一个关系中的一组 contig”。

- 顶点 V：所有 contig（可选过滤：长度 < 1–2 kb 的 contig 先排除或延后处理）
- 证据层与超边 E 的构建（每一层形成一组加权超边）
  - 组成层（Composition）
    - 特征：四核苷酸频率（tetramer）、可能加上长 k-mer PCA/ICA/UMAP
    - 方式：对每个 contig 取 kNN（互为 kNN 更稳健），形成一个超边（该 contig及其邻居）；权重与“相似度”相关（如余弦相似度、Mahalanobis 距离的核转换）
  - 共丰度层（Co-abundance）
    - 特征：样本覆盖向量（可对数变换+标准化；跨样本批次效应可经 ComBat/中位数归一）
    - 方式：按相关性/距离（Pearson/Spearman/cosine）取 kNN，形成超边；或按样本聚类先分组再局部扩展
  - 装配图层（Assembly graph）
    - 数据：GFA 中的边/路径；或从 BAM 统计边支持
    - 方式：以每个 contig 为中心取 r-hop 邻域形成超边；权重与边支持强度、路径一致性相关
  - 成对链接/Hi-C 层（PE/Hi-C/Long-read）
    - 方式：对“共享强链接的子集”做团簇化再做超边；或将高权值链接的局部团聚作为超边（避免只做二元边）
- 超边权重设计
  - 归一化到 [0,1] 或按层再缩放 α_i；对高基数超边做惩罚，避免大超边主导
- 稀疏表示
  - 用稀疏关联矩阵 H ∈ {0,1}^{n×m} 表示顶点-超边关系，W 为对角的超边权重

## 规范化超图拉普拉斯与谱聚类（理论依据）

采用 Zhou 等提出的规范化超图拉普拉斯（常用且稳健）。

- 关键矩阵
  - H ∈ {0,1}^{n×m}：顶点-超边关联矩阵
  - W ∈ R^{m×m}：超边权重对角矩阵
  - D_v ∈ R^{n×n}：顶点度对角矩阵，d(v) = ∑_{e} w(e) H_{v,e}
  - D_e ∈ R^{m×m}：超边度对角矩阵，δ(e) = |e|（或其他定义，但 |e| 常见稳健）
- 规范化拉普拉斯（Zhou 2006）
  - L = I − D_v^{-1/2} H W D_e^{-1} H^T D_v^{-1/2}
- 聚类步骤
  1) 计算 L 的前 k 个最小特征向量（稀疏 Lanczos/LOBPCG）
  2) 得到嵌入矩阵 U ∈ R^{n×k}（按行归一化）
  3) 对 U 做 k-means（多次重启取最佳）
- 多层融合
  - 对每个证据层 i 构建 L_i，做加权和：L_total = ∑_i α_i L_i（α_i 可基于层内信噪比/稳定性评分自动调）
  - 优点：各层尺度对齐且易于调参；避免粗暴 clique expansion 对大超边的偏置
- k 的选择（无监督）
  - 谱隙（eigengap）启发式：λ_k 与 λ_{k+1} 间隙最大
  - 稳定性：k-means 多随机种子、子采样稳定性指数、silhouette/bic（嵌入空间）
  - 约束：最小 bin 大小、CheckM 追踪趋势（仅用于辅助，不直接过拟合）

## 初始分箱与细化

- 初始分箱：来自谱聚类标签
- 细化一（EM/GMM 融合 Coverage+Composition）
  - 在每个初始 bin 内，对双模态特征（组成+共丰度）拟合 GMM，剔除离群子簇，或把不确定 contig 标记为“未分配池”
- 细化二（图/超图标签传播）
  - 在装配图/Hi-C 层上做半监督传播，将高置信 bin 向邻域扩展；对低置信边/噪声设阈值与冷却调度，防止错误扩散
- 细化三（SCG 约束与去污染）
  - 基于单拷贝标记基因（SCGs）计数与冗余，分裂/合并子簇；强制每 bin 的 SCG 冗余最小化

## 架构总览

- 核心理念：用“多层超图”统一多源证据（组成、共丰度、装配图、Hi‑C/成对链接），在统一的规范化超图拉普拉斯上做谱聚类，之后通过半监督传播、GMM/EM 和 SCG 约束进行细化与去污染。
- 分层模块：
  - IO/Features：原始数据读写与特征抽取
  - Hypergraph：各证据层→超边集合→规范化矩阵
  - Spectral：超图谱嵌入与聚类、k 选择
  - Refine：标签传播、GMM/EM、SCG 驱动的分裂/合并
  - Evaluate：CheckM/CheckM2、ARI/AMI、汇总表
  - Viz：嵌入/热图/桑基等图表
  - Pipeline：端到端编排、可重跑、缓存与日志
  - CLI/Config：配置化运行、子命令分步或一键

## 核心数据结构与存储

- 基本实体
  - ContigRecord：id/name、length、GC、k‑mer 向量、覆盖度向量、可选注释与SCG计数
  - CoverageMatrix：稀疏或稠密的 contig×sample 浮点矩阵（标准化前后都持久化）
  - Hyperedge：{layer_id, members: List[int], weight: float, meta: dict}
  - HypergraphLayer：H_layer（n×m 稀疏二值）、W_layer（m×m 对角，向量形式存）、D_v_layer、D_e_layer 与构建元数据
  - Hypergraph: 多层集合 + 融合策略（α_i）
- 稀疏矩阵存储
  - 关联矩阵 H：scipy.sparse.csr_matrix（内存）+ .npz 或 zarr/hdf5（磁盘）
  - 大规模场景：每层 H 分块存储（按 contig 分区），支持惰性加载与逐层合并
- 序列化
  - 表格：parquet/csv（contigs.tsv、bins.tsv、metrics.tsv）
  - 大矩阵：.npz/zarr（可 memmap），确保跨平台（Windows 下避免超长路径，路径统一使用相对路径+短文件名）

## 计算与性能策略（规模与鲁棒性）

- 规模控制
  - 预过滤短 contig（如 <1–2 kb）进入“延后池”，先用长 contig 建模，细化阶段再分配短 contig
  - kNN 构图采用近似方法（FAISS/Annoy，可作为可选依赖），或分桶（按长度/覆盖）局部搜索
  - 超边基数上限与权重惩罚，避免超大超边主导
- 稀疏线性代数
  - L 的 eigsh 仅取前 k（k 上限可 100–200），oblivious warm‑start 与多线程 BLAS
  - 内存峰值监控与分块重用：避免复制大稀疏矩阵
- 并行与缓存
  - 证据层独立可并行；特征抽取与近邻搜索多进程/线程
  - 强缓存粒度：特征→层→谱嵌入→聚类；参数哈希快照
- Windows 兼容性
  - 路径与进程安全：避免过深目录；multiprocessing 使用 “spawn” 兼容模式；文件锁保障缓存一致性

## 细化与约束的设计要点

- EM/GMM：在（PCA_tetramer ⊕ normalized_coverage）空间内部细化；BIC/最小样本阈值防止过拟合
- 标签传播：只用高置信的图/Hi‑C 边，逐步降阈扩展，设回退（若污染上升则撤销）
- SCG 约束：冗余触发 bin 分裂或移除少量 contig；保持单拷贝基因集合的唯一性

## 与 Hi‑C 的本质差异与机会
- Pore‑C 是基于 ONT 的多接触 3C：单条读段可跨多个片段，形成“同一时空近邻”的多路连接；Hi‑C 通常以成对片段为主。
- 直接做两两投影（clique expansion）会夸大大超边的影响；超图建模能保留“同一次多路接触”的整体性，并通过对超边基数进行惩罚抑制虚高权重。
- 长读段误差率更高、比对跨度更长，更容易跨重复区，但也更易引入拼接伪阳性，需要更严格的读段级过滤与权重折减。

## 理论架构

### 1) 多层超图统一建模
- 顶点 V：装配得到的 contigs（先过滤短 contig，如 <1.5–2 kb）
- 层 E：
  - Composition 层：k‑mer（如 4‑mer）特征的 kNN 超边
  - Co‑abundance 层：覆盖向量相似性的 kNN 超边（log1p+zscore）
  - Assembly 层（可选）：装配图 r‑hop 邻域/团聚形成超边
  - Pore‑C 层（本工作重点）：每条多接触读段 → 一个超边 e，成员为该读段对齐到的所有 contig 的集合
- 每层都有自己的 H_i（n×m_i 关联矩阵）与权重向量 w_i（超边权重）

### 2) 规范化超图拉普拉斯（Zhou 2006）
- 记 H 为关联矩阵，W 为超边权重对角，D_v 顶点度，D_e 超边度
- 拉普拉斯 L = I − D_v^{-1/2} H W D_e^{-1} H^T D_v^{-1/2}
- 多层融合：L_total = Σ_i α_i L_i（α_i 为层权重；见参数建议）
- 直觉：D_e^{-1} 会对大超边做“稀释”，避免大规模多接触读段主导

### 3) 聚类与细化
- 对 L_total 求最小的 k 个特征向量 → 谱嵌入 U → k‑means
- 细化：
  - 标签传播（只在 Pore‑C/装配图的高置信边上）
  - GMM/EM 在（composition ⊕ abundance）的子空间内对每个 bin 清理离群
  - SCG 约束（单拷贝标记基因）驱动合并/拆分与去污染

## Pore‑C 特化实现流程

### A. 映射与读段级过滤（输入→可靠多接触集合）
- 比对：minimap2（map‑ont 预设）比对读段到 contigs；保留主比对，MAPQ ≥ 20–30
- 片段划分：按读段上的有序对齐片段（segment），每个 segment 至少覆盖 L_min（建议 1–2 kb，随组装质量调）
- 过滤规则（读段级）：
  - 去除仅落在单一 contig 的读段（无信息）
  - segment 数 ≥ 3（建议用于“多接触”判据）；若只用 pair‑like，也可放宽至 ≥ 2
  - 全局低复杂度/多重命中段（高二级比对得分）剔除
  - 读段覆盖比例（对总长）≥ τ_cov（如 0.6），避免碎片化对齐
- 片段级过滤：
  - 单段 MAPQ ≥ q_min（如 20）
  - 段长 ≥ l_min（如 500–1000 bp）或“有效碱基数”（剔除软剪/低质）

为何：提升精确度，降低跨重复区与测序错误导致的跨样本假连接。

### B. Pore‑C 超边构建与加权
- 超边定义：每条通过过滤的读段 r → 超边 e_r = {c_1, c_2, …, c_k}
- 权重 w(e_r) 的合理设计（兼顾信息量与稳健性）：
  - 基本权重：1 或 log(1 + k)，k 是成员数（多接触略加分）
  - 基数惩罚：除以 (k − 1) 或 δ(e)（Zhou 中的 D_e），抑制特别大的超边
  - 质量修正：乘以 f(平均 MAPQ、最短 segment 长度、读段长度占比)
  - 冗余去重：同一读段若在极短范围内出现重复对齐模式，只计一次
- 可选“局部拆分”策略：若 e_r 很大且成员间存在明显相似性子团（按覆盖/组成），可把 e_r 切为若干子超边，避免“跨多个生态位”的粗连接

为何：保留“同一次多接触”的整体性，同时限制超大超边的过度影响。

### C. Pore‑C 层的偏倚校正与噪声控制
- 顶点归一：按 contig 长度与 mappability 调整度（近似可用长度归一和度截断）
- 读段权重裁剪：w(e) 上限（如分位数 99%）+ 置信度阈值
- 互证据一致性筛选（可选）：仅保留与 composition/co‑abundance 一致性较高的 Pore‑C 边（降低跨物种假阳性）
- 距离衰减（读段上的片段距离）：相邻片段的“读段距离”越远，惩罚越强；多段之间可按最小间距的函数折减

为何：Pore‑C 受片段长度、可比对性等偏倚影响，适度校正更稳。

### D. 多层融合与谱聚类
- 层权重（初始建议，可随数据调整）：
  - α_comp = 0.35、α_abund = 0.35、α_porec = 0.30（若无多样本覆盖，可加大 α_porec 至 0.45）
  - 若有装配图层：α_asm = 0.15，并相应缩小其他权重，保持 Σ α_i = 1
- k 的选择：谱隙 + 稳定性（子采样+多次重启）；对极端不稳定的 k 自动回退到次优稳定解

### E. 细化策略（用 Pore‑C 做“可信扩展”，不用它做“强制合并”）
- 高置信标签传播：仅在“Pore‑C 权重高且 composition/co‑abundance 不冲突”的边上扩展
- EM/GMM：以（PCA_tetramer ⊕ normalized_coverage）为特征，在每个 bin 内进行 1→2 子簇分裂检验（BIC/阈值）
- SCG 守护：若某 bin 的单拷贝基因出现冗余，优先分裂连接度较弱的子团，或回退标签传播

### F. 评估与消融（Pore‑C 的增益量化）
- 指标：CheckM/CheckM2、MIMAG 分档；若有真值：ARI/AMI、per‑species recall/precision
- 消融：仅 Composition+Abundance vs 加上 Pore‑C；若有装配图，则再加 “+Assembly”
- 报告：Pore‑C 层引入后，高质量 MAG 数、污染度、未分配比例、资源开销的变化

## 总体架构（不分层、不用深度学习）
- 用 Pore‑C 读段构建一个“单一接触结构”（两种等价选择，二选一）：
  1) 单一加权图 G：顶点是 contigs，边权是“经质量与偏倚校正后的有效共接触强度”（将多接触读段投影为配对累计，但采用严格的去偏与基数惩罚避免大团边膨胀）。
  2) 单一超图 H（可选）：保持读段的多接触为超边，在算法阶段直接做“图划分目标”的等价配对化（最终仍用图优化）。这保持概念整洁，但实现上我会默认落地为“加权图”，因为现有社区检测/划分工具链更成熟。
- 用传统图划分/社区检测完成分箱：
  - 优先推荐：加权 Leiden（或 Louvain）优化可分辨率模块度（CPM/γ‑modularity），或归一化割（NCut）/RatioCut 的谱划分（无需神经网络）。
  - 自动选簇数：扫描分辨率参数 γ 或基于稳定性与谱隙选择。
- 细化与质量控制：局部移动（Kernighan‑Lin 风格）、弱连通剥离、短 contig 的后分配；SCG/CheckM 仅用于“质控与汇报”，不进主体目标函数（符合“单一结构”要求）。

这套方法只依赖 Pore‑C 接触信号与基础对齐质量指标；不引入多层合模，也不用深度模型。

## 端到端实现流程（逐步可落地）

### 1) 比对与读段预处理（BAM/SAM → 合格的多接触事件）
- 比对建议：minimap2 map‑ont（你已有 BAM/SAM 就直接用），仅保留主比对（primary），过滤 MAPQ < 20–30。
- 将每条读段切分为按基因组顺序的对齐片段（segment），只保留长度 ≥ l_min 的片段（建议 500–1000 bp；装配碎片多时可放宽，但要配合更严格的去噪）。
- 读段级过滤：
  - segment 数 ≥ 3（多接触定义）；若样本稀疏，可暂时允许 =2，但精度会降。
  - 读段上可解释比例 ≥ 0.6（有效比对覆盖/总长），剔除碎片化/高度噪声的读段。
  - 丢弃仅落在单一 contig 的读段（无跨 contig 信息）。
- 片段级过滤：
  - 单段 MAPQ ≥ 20；对潜在多重命中的片段（secondary/补充记录）剔除或降权。
  - 合并同一读段中“落在同一 contig 相邻区域”的多个片段为一个命中，以免重复计数。
- 去重与异常：
  - 按 read_id 去重复；如有分子条形码（有些 Pore‑C 方案会有），按分子去重优先。
  - 极端长的读段若跨过大量 contig（> k_max，例如 12–20），要么裁剪最弱段，要么将该读段弃用/拆分，避免伪全连接。

产出：每条合格读段 m 的“contig 集合” E_m = {i1, i2, …, ik}。

### 2) 从多接触到“有效配对权重”（构建单一加权图）
目标：将多接触事件合理地汇总为配对边 A_ij，但避免把一个大超边扩张为过强全连 clique。

- 基数惩罚的配对投影：
  - 对读段 m（|E_m|=k），对 E_m 中每个无序对 (i,j)，累加 w_m(i,j) = q_m / (k − 1)。
    - q_m 是读段质量分：q_m = f(平均 MAPQ、最短 segment 长度、读段覆盖比例) ∈ (0,1]。
    - 直觉：一次多接触贡献被均匀分摊，k 越大，单对的增量越小。
- 重复/低复杂度惩罚：
  - 若 i 或 j 是“高度可比对的重复 contig”（在 BAM 中显示出异常高的对齐覆盖或多重命中比率），对该对的增量再乘以 1 / (1 + ρ_i + ρ_j)。
- 读段内部距离衰减（可选但实用）：
  - 在读段的 segment 序列上，(i,j) 的间距越远，贡献衰减更强；例如乘以 exp(−Δ/τ)，Δ 为 segment 索引差或碱基间隔近似。
- 合成得到初始边权 A_ij = Σ_m w_m(i,j)。

这一步只用 Pore‑C 信号；没有其他“层”。

### 3) 偏倚校正与权重缩放（提高可划分性与稳健性）
- 节点度归一（度校正的筛选或平衡）：
  - 计算 d_i = Σ_j A_ij；对极端 hub（高 d_i）做截断或缩放：A_ij ← A_ij / (d_i^α d_j^α)，α∈[0.3,0.5]。
  - 或做简单的对称归一：Â = D^{-1/2} A D^{-1/2}（便于谱划分）。
- ICE/平衡化（可选，Hi‑C 领域常用思想，适用于校正系统偏倚）：
  - 迭代比例拟合（IPF/ICE）使矩阵行列和近似相等；在宏基因组场景不需要到收敛，做 5–10 次迭代通常已改善系统性偏倚。
- 权重裁剪与去噪：
  - 将 A_ij 做上分位裁剪（如 99% 分位），抑制极端异常边；去除 A_ij < ε 的微弱边以稀疏化（ε 依数据规模定）。
- 最小支持：
  - 丢弃仅由 1 个读段支持的边，或把单读段支持权重乘以小系数（例如 0.5），提高可重复性。

这一步主要解决长读长误差与重复区带来的 hub 偏差。

### 4) 图划分（得到初始 bins）
两种成熟路线，都不需要神经网络：

- 路线 G1：加权 Leiden（或 Louvain）
  - 目标函数：可分辨率模块度（CPM）或 γ‑modularity。γ 为分辨率参数，γ 大→更多小簇，γ 小→更少大簇。
  - 选择 γ：扫描 γ ∈ Γ（例如从 0.5 到 5 的若干值），按稳定性（多次随机种子）与“簇内接触密度/簇间稀疏度”评分选取。
  - 优点：快速、工程上稳；缺点：簇数受 γ 影响，需要扫描与选择。
- 路线 G2：谱划分（Normalized Cut）
  - 用对称归一化拉普拉斯 L = I − D^{-1/2} A D^{-1/2}，取前 k 个最小特征向量，k‑means 得到 k 簇。
  - k 的选择：看谱隙与稳定性；或使用逐步二分（每次把最差簇按最小二乘切分）直到达标。
  - 优点：理论清晰；缺点：需要选 k 或二分终止条件。

建议优先 G1（Leiden），因为对超大图更稳、参数更少；G2 作为备选或用于可视化（嵌入）与 sanity check。

### 5) 细化与后分配（稳住结果、处理短 contig）
- 局部移动/交换（Kernighan‑Lin 风格）：
  - 在固定簇数下，允许单个或一小撮 contig 跨簇移动，只接受能提高“簇内权重 − 簇间权重”的动作。
- 弱节点剥离：
  - 对每个 bin，计算节点的簇内联系强度 s_in 与簇间强度 s_out；若 s_in / (s_out + δ) < θ，则将该节点标为“未分配”待二次处理。
- 短 contig 后分配：
  - 对未参与初始划分的短 contig（长度 < L_short，例如 1500–2000 bp），按其与各 bin 的 A_ij 总和（或 top‑k 接触）做最近邻投票分配；若最高票与次高相差不大，则保持未分配。
- 合并/拆分：
  - 极小 bin（低于最小 contig 数或总长度阈值）尝试并入最相近的邻 bin；SCG 冲突（同一 bin 出现明显冗余）时，沿接触最弱的割拆分。

注意：SCG/CheckM 只用于“决策参考”，不是主目标函数的一部分，符合“单结构”原则。

### 6) 评估与报告
- 无真值：CheckM/CheckM2 的 completeness/contamination；按 MIMAG 分档统计；未分配比例、每 bin 的 N50 与 GC 分布。
- 有真值：ARI/AMI、每物种 recall/precision、碎片化程度。
- 资源与规模：节点数（contigs）、边数、运行时间与内存，记录参数以复现。

## 简洁的数学目标（图划分视角）
- 加权模块度（带分辨率 γ）：
  - maximize Q = Σ_{ij} [A_ij − γ P_ij] δ(c_i, c_j)
  - P_ij 是空模型（常取 (d_i d_j)/(2m) 或常数 CPM）；γ 控制簇数偏好
- 或归一化割（NCut）：
  - 最小化 Σ_{partitions} cut(S, S̄)/vol(S)
- 与我们构建的 A_ij 配套：由于做了度校正/ICE，Q 的优化更容易朝“高内密度、低外密度”的簇靠拢。

## 关键参数的默认起点（可据你的数据微调）
- 对齐质量阈值：MAPQ ≥ 20–30；segment 长度 ≥ 500–1000 bp；读段解释比例 ≥ 0.6
- 多接触基数：读段内成员数上限 k_max = 12–20；超出则裁剪或丢弃
- 边权构建：w_m(i,j) = q_m/(k−1)，q_m ∈ [0.5,1.0]（按读段质量线性映射）；单读段支持边降权
- 度归一：α = 0.3–0.5；或使用对称归一 D^{-1/2} A D^{-1/2}
- 稀疏化：删除 A_ij < ε（如分位 60–80% 的小权重按规模选）；上分位裁剪 99%
- 图划分（Leiden）：γ 扫描在 {0.5, 1.0, 1.5, 2.0, 3.0}；每个 γ 重复 10 次随机种子取稳定性最高
- 最小 bin：≥ 10–20 个 contig 或总长度 ≥ 200 kb（按样本复杂度调）

## 风险点与对策
- 重复区域导致的 hub 节点：度归一/截断 + 低复杂度 contig 降权；必要时把这类节点延后分配
- 超长读段跨过多个生态位：k_max 限制、读段质量 q_m 严格、子序列一致性检查（相邻 segment 的 contig 组合是否频繁共现）
- 稀疏样本：如果接触极稀疏，先只做强边图（高阈值），得到核心 bins，再逐步放松阈值扩展
- 规模：若边数过大，先保留每个节点的 top‑K 邻（例如 K=100–300）再做划分；或分块处理后合并

## 为什么用超图（契合 Pore‑C 的信息形态）
- Pore‑C 一条读段常同时命中多个 contig，天然是“一个读段构成一组接触”的高阶关系。把它压成两两边（clique expansion）会夸大大团边、丢失“同一次接触”的整体性。
- 超图直接把“多接触事件”作为一个超边，后续用规范化超图拉普拉斯做谱聚类，既保留事件整体性，又通过“基数归一+正则化”抑制大超边主导。

## 数学建模（超图与谱聚类）

- 顶点集：V（每个顶点是一个 contig，数量 n）
- 超边集：E（每条合格 Pore‑C 读段 m 生成一个超边 e_m⊆V，数量 m）
- 关联矩阵：$H\in\{0,1\}^{n\times m}$，$H_{ve}=1$ 表示顶点 v 在超边 e 内
- 超边权重：$W=\mathrm{diag}(w_e)$，$w_e>0$
- 顶点度与超边度：
  - $d(v)=\sum_{e\in E} w_e H_{ve}$，记 $D_v=\mathrm{diag}(d(v))$
  - $\delta(e)=|e|$（或用其他定义，如有效成员数），记 $D_e=\mathrm{diag}(\delta(e))$

常用的规范化超图拉普拉斯（Zhou 等，2006）：
- 对称规范化形式：
  $$
  L = I - D_v^{-1/2} \, H \, W \, D_e^{-1} \, H^\top \, D_v^{-1/2}
  $$
- 随机场（随机游走）形式：
  $$
  L_{rw} = I - D_v^{-1} \, H \, W \, D_e^{-1} \, H^\top
  $$

超图割（如 N‑cut）的连续松弛解对应于上式的特征向量：取最小的 k 个特征值对应的特征向量做嵌入，再在嵌入空间用 k‑means 得到簇（bins）。

直觉：
- $D_e^{-1}$ 会自然“稀释”大超边的贡献（基数越大，单顶点对的耦合越弱），避免 clique expansion 带来的偏置。
- $D_v^{-1/2}$ 做顶点度归一，抑制 hub（重复/高可比对 contig）主导。

## Pore‑C 超边权重的构造（关键）
对每条通过过滤的读段 r，设其命中 contig 集为 $e_r$，$k=|e_r|$。建议权重：
- 基础权重（质量分）：$q_r\in(0,1]$，由“平均 MAPQ、最短 segment 长度、读段解释比例（对总长的覆盖）”映射而来，质量越高 $q_r$ 越大。
- 基数惩罚：$w_{e_r} \propto q_r / (k-1)$ 或 $q_r / k$（与 $D_e^{-1}$ 协同，避免大超边放大）。
- 读段内部距离衰减（可选）：若读段上 segment 间距（索引差/碱基间）较远，则对 $q_r$ 乘以 $\exp(-\Delta/\tau)$（$\tau$ 为尺度）。
- 可比对性/重复度修正（顶点层面）：对易成 hub 的 contig（高二级比对率、异常覆盖），其加入任何超边时可将 $w_e$ 乘以 $1/(1+\rho_v)$ 的平均因子（或后续在 $D_v$ 层统一正则，见下）。
- 上下分位裁剪：对 $w_e$ 做上分位截断（例如 99% 分位），去掉极端大权重；同时可丢弃 $w_e$ 极小的边以控稀疏度。
- 超大超边处理：若 $k>k_{max}$（如 12–20），优先裁剪边中最弱/最不一致的成员或拆分为若干子超边；过大超边往往来自跨多生态位的伪连接。

质量过滤前置（保证 $w_e$ 有意义）：
- 读段层：primary 比对；MAPQ ≥ 20–30；解释比例 ≥ 0.6；segment 数 ≥ 3（多接触）；去除只命中单 contig 的读段
- 片段层：segment 长度 ≥ 500–1000 bp；去二级/多重命中；相邻落在同一 contig 的片段合并

## 聚类流程（谱方法，无需神经网络）

1) 构建超图
- 从 BAM/SAM 生成合格读段的 $e_r$ 与 $w_{e_r}$，写出 $H$（稀疏）与 $W$。
- 计算 $D_v$ 与 $D_e$。对 $D_v$ 可做轻度截断（cap）或平滑，避免极端 hub。

2) 计算规范化拉普拉斯
- $L$ 或 $L_{rw}$，优先 $L$（对称形式便于用对称特征分解），稀疏存储。

3) 特征分解与嵌入
- 取最小的 k 个特征对（Lanczos/eigsh/LOBPCG）；将得到的嵌入矩阵 $U\in\mathbb{R}^{n\times k}$ 行归一化（每行单位范数）。

4) 聚类
- 对 $U$ 行做 k‑means（多次重启取最佳），得到初始 bins。

5) k 的选择（无监督）
- 谱隙启发：查看特征值序列 $(\lambda_1,\dots,\lambda_n)$ 中最大的“间隙”，取前 k
- 稳定性：对多个随机子采样重复聚类，取稳定性最优的 k
- 约束：最小 bin 大小/总长度阈值（防止过分裂）

复杂度与工程要点：
- $H$ 与 $L$ 都是稀疏的；时间主要在稀疏特征分解，复杂度约为 $O(\mathrm{nnz}(L)\cdot k \cdot \mathrm{iters})$。
- 控制 nnz：过滤弱边（小 $w_e$）、限制 $k_{max}$、分块构建与序列化。

## 细化与后处理（在超图上做半监督改进）

- 超图标签传播（只用高置信超边）
  - 固定高置信 bins 的标签，对“未分配/低置信”的顶点做几轮传播：
    $$
    Y^{(t+1)} = \alpha \, \Theta \, Y^{(t)} + (1-\alpha) \, Y^{(0)}
    $$
    其中 $\Theta = D_v^{-1} H W D_e^{-1} H^\top$ 或其对称归一版本；仅在 $w_e$ 超过阈值、且与当前簇一致性高的超边上启用，避免错误扩散。
- GMM/EM（可选，特征为空间坐标来自谱嵌入 U 或少量可解释特征，如 GC/长度）：对单个 bin 内检测离群并剔除回未分配池。
- SCG（单拷贝基因）守护（仅作后验质控，不入目标函数）：若某 bin 出现明显 SCG 冗余，优先沿“超图连接最弱”的割拆分；若 SCG 缺失但簇结构稳定，可保留（避免过度依赖功能信号）。

短 contig 后分配：
- 初始只对 ≥1.5–2 kb 的 contig 做谱分解；短 contig 通过“与各 bin 的超边共现强度”投票分配，若不确定则保持未分配。

## 与“把超图压成图”的对比（何时用哪种）
- Clique expansion（完全子图）：简单但会放大大超边；不推荐直接用在 Pore‑C 的多接触上。
- Star/bipartite expansion（顶点‑超边二部图）：保留高阶结构，但最终仍需在二部图上做图算法；等价于显式使用 $H$／$W$ 的谱方法。
- 直接超图谱（上述 $L$）：更干净且与高阶目标匹配；工程上只要掌握稀疏矩阵算子即可。

## 参数默认值（首轮跑通的安全起点）
- 过滤：MAPQ ≥ 20–30；segment ≥ 500–1000 bp；读段解释比例 ≥ 0.6；segment 数 ≥ 3
- 超边规模：$k_{max}=12\text{–}20$；超出拆分/裁剪
- 权重：$w_e = \min\{q_r, q_{cap}\}/(k-1)$，$q_{cap}$ 取 0.9–0.95；上分位裁剪 99%
- 稀疏化：丢弃 $w_e$ 小于全局分位（如 60–80%）的超边；对低支持（仅 1 条读段）超边降权或剔除
- 拉普拉斯：优先 $L$（对称形式）；特征分解取 $k\in[20,200]$ 扫描（按规模调）
- 聚类：k‑means 重启 20 次；最小 bin 长度 ≥ 200 kb 或 contig 数 ≥ 10–20

## 失败模式与对策
- 超大/跨生态位超边造成“粘连”：基数惩罚 + $k_{max}$ 限制 + 拆分子超边
- 重复区 hub 导致簇塌缩：顶点度截断/平滑；对高重复 contig 延后分配
- 接触稀疏：先用强边构建稀疏超图（高阈值），得到核心簇，再渐进式放松阈值+标签传播
- 算法规模瓶颈：分块构建 $H$；特征分解只用前 k、小心内存峰值；必要时把“弱超边”先行丢弃

## 1. 读 contigs（建立索引）

## 2. 从 BAM/SAM 生成“超边流”
- 文件：`io/bam.py` 的 `iterate_porec_hyperedges`
- 做什么（逐读段处理）：
  - 用 pysam 迭代 BAM/SAM，把同一 read 的对齐片段聚到一起（建议 BAM 先按 read 名排序 name-sorted）。
  - 过滤每个片段：MAPQ ≥ `mapq_min`，片段对齐长度 ≥ `segment_min_bases`。
  - 过滤每条读段：片段数 ≥ `min_segments_per_read`（默认 3，保证“多接触”）；这条读段的可解释比例（对齐到参考的长度 / 读段总长）≥ `read_coverage_min`（默认 0.6）。
  - 把这条读段命中的 contig 去重、按首次出现顺序保留；如果成员数 > `max_hyperedge_size`（默认 20），截断到阈值。
  - 计算读段质量分 q_r（0.2 到 1.0 之间）：综合平均 MAPQ、最短片段长度、读段解释比例三个维度，越高越可信。
  - 产出一个超边：(成员 contig 名列表，q_r)。
- 输出：一个生成器，源源不断 yield `(List[str], float)`。

为什么：
- 只有多接触读段（≥3）才提供“同时命中多 contig”的高阶关系。
- MAPQ 和片段长度过滤能去掉明显噪声；解释比例保证这条读段不是“碎片化错配”。
- 对特别大的读段（跨很多 contig）截断，避免生成“几乎全连的超边”。

注意：
- 现在实现默认按名称分组读取，强烈建议 BAM 先 `samtools sort -n`。坐标排序的 BAM 容易把同一 read 拆开，导致分组不准。我可以按需把分组逻辑改成“稳妥的按 read 全量聚合”（但会更占内存）。

## 3. 构建稀疏超图 H（n×m）
- 文件：`hypergraph/build.py` 的 `build_from_porec`
- 做什么：
  - 把第 2 步里的 contig 名换成整数索引。
  - 为每条超边 e（成员数 k≥2）计算权重：`w_e = min(q_r, 0.95) / (k - 1)`；把成员写入 H（顶点‑超边关联矩阵，0/1）。
  - 计算每条超边的“度”（de = k）、每个顶点的“度”（dv = Σ w_e）。
- 输出：`Hypergraph(H, w, de, dv, contig_names)`，其中 H 是 csr 稀疏矩阵，w/de/dv 都是向量。

为什么这样定权重：
- 同一条读段的总“信任” q_r 固定，成员越多，分到任意一对/一个顶点的强度越弱（/ (k-1)）。
- 后面拉普拉斯里还会用到 `D_e^{-1}`（按 |e| 稀释），两者协同抑制“大超边主导”的偏置。

## 4. 拉普拉斯线性算子 L（矩阵自由）
- 文件：`hypergraph/laplacian.py` 的 `make_L_linear_operator`
- 做什么：
  - 定义一个只实现“矩阵乘向量”运算的算子，表示
    L = I − D_v^{-1/2} H W D_e^{-1} H^T D_v^{-1/2}。
  - 乘法顺序是逐步稀疏乘，让内存占用保持在稀疏水平，不构造 n×n 稠密矩阵。
  - 对 dv=0 的顶点做了“安全除法”（用 1 兜底），避免除零。
- 输出：`LinearOperator`，形状是 (n, n)，可以直接喂给 eigsh。

为什么：谱分解需要和 L 反复做乘法，矩阵自由能省掉巨大的内存，并且计算更快。

## 5. 谱嵌入（取最小的 k 个特征向量）
- 文件：`spectral/eigen.py` 的 `spectral_embedding`
- 做什么：用 `scipy.sparse.linalg.eigsh` 求 L 的 k 个最小特征值/特征向量，按特征值从小到大排序，返回特征向量矩阵 U（n×k）。
- 输出：U（每行对应一个 contig 在 k 维嵌入空间的坐标）。

为什么：超图 N‑cut 的连续松弛解就是这些最小特征向量的张成空间（直觉是：相似的点在低维会“挤在一起”）。

## 6. k‑means 聚类（得到 bin）
- 文件：kmeans_cluster.py 的 `kmeans_labels`
- 做什么：
  - 先对 U 做“按行归一化”（每个 contig 的 k 维向量变成单位长度），让 k‑means 更稳定。
  - 用 scikit‑learn 的 KMeans 跑 n_init=20 次重启，取最佳解。
- 输出：`labels`（长度 n 的整数向量），我在落盘时把它格式化成 `bin_0、bin_1...`。

为什么：谱聚类经典套路——先谱嵌入，再用简单的 k‑means 切分。

- 内存占用由“存整张 H（n×m）”降到“存一个长度为 n 的 dv + 按块读边”

## 1) 从 BAM/SAM 生成“多接触超边”
- 文件：bam.py
- 入口：`iterate_porec_hyperedges(bam_path, contig_name_set, flt)`
- 做了什么
  - 用 pysam 逐条读 BAM/SAM，把同一个 read 的对齐片段聚到一起（建议 BAM 先按 read 名排序 name-sorted）
  - 过滤片段：MAPQ ≥ `mapq_min`；单段对齐碱基数 ≥ `segment_min_bases`
  - 过滤读段：片段数 ≥ `min_segments_per_read`（默认3，保证“多接触”），解释比例（被比对的碱基/读段总长） ≥ `read_coverage_min`
  - 去重得到“该读段命中的 contig 列表”，若成员数 > `max_hyperedge_size`（默认20），截断
  - 按平均 MAPQ、最短片段长度、解释比例综合出“质量分” q_r（范围约 0.2–1.0）
  - 产出：`(成员contig名列表, q_r)` 的生成器，一条读段对应一条“超边”
- 为什么
  - 只有“多接触”才表达“同一次近邻性”的高阶关系
  - MAPQ/长度/解释比例过滤能有效抗噪，截断超大超边防“全连”效应

小心
- 强烈建议 BAM 先 `samtools sort -n`，否则同一 read 的片段可能不连在一起（当前实现假定 name-sorted 更高效）

## 2) 把超边落到磁盘（流式大图默认）
- 文件：stream.py
- 入口：`write_edge_chunks(n_vertices, edge_iter, out_dir, q_cap, chunk_size)`
- 做了什么
  - 把“超边流”按块写到 `edges_chunks/edges_chunk_*.npz`
  - 每块保存四个数组（类似 CSR 存法）：
    - `idx_flat`: 把每条超边的顶点索引拼起来
    - `ptr`: 每条超边在 `idx_flat` 的起止位置（长度 = 边数+1）

    - `de`: 每条超边的基数 |e|
  - 同时一遍累计顶点度 dv（每个顶点的度是它 incident 的所有超边权重之和）
- 权重怎么定
  - 一条读段的超边 e，成员数 k≥2
  - `w_e = min(q_r, q_cap) / (k - 1)`（默认 `q_cap=0.95`）

- 为什么
  - 2万+ contigs、海量读段时，把完整 H 放内存很吃力；分块落盘后，谱分解时“逐块乘法”就行
  - 一遍累 dv，后面拉普拉斯规范化要用

可调
- `streaming.edges_per_chunk` 控制每块的超边数（默认 200,000）；内存紧就调小

## 3) 拉普拉斯算子：矩阵自由乘法
- 对称规范化超图拉普拉斯（Zhou 2006）
  - L = I − D_v^{-1/2} H W D_e^{-1} H^T D_v^{-1/2}
- 两种实现（都会是“矩阵自由”，不造 n×n）
  1) 非流式（小图）：`hypergraph_binning/hypergraph/laplacian.py::make_L_linear_operator`
  2) 流式（大图）：`hypergraph_binning/hypergraph/stream_operator.py::StreamingHypergraphOperator`
     - 乘法过程（每次 `L @ x`）：
       - 先做 y = D_v^{-1/2} · x
       - 逐块读边，按 `ptr` 在 `idx_flat` 上切出每条超边成员，计算 s_e = Σ_{v∈e} y[v]
       - 得到每条边的“增益” gain_e = (w_e / |e|) * s_e
       - 把 gain_e “散加”回该超边的所有成员（np.add.at），累到 accum
       - 最后 z = D_v^{-1/2} · accum，返回 x − z
- 为什么
  - 谱分解只需要“算子乘向量”，这种写法能支持超大 n 与海量边（块读、块算、块加）
